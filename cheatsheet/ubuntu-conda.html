Ubuntu conda

Conda cheatsheet 
=== install conda
wget -c https://repo.anaconda.com/miniconda/Miniconda3-py39_23.1.0-1-Linux-x86_64.sh

For python 3.13:
wget -c https://repo.anaconda.com/miniconda/Miniconda3-py313_25.5.1-1-Linux-x86_64.sh

Disable cache:
export XDG_CACHE_HOME="/project/dl2025s/velikanm/.cache"

bash ./Miniconda3-py313_25.5.1-1-Linux-x86_64.sh -b -f -p $PWD/miniconda
(b - batch, f - overwrite, p - installation prefix)
conda config --set auto_activate_base False

=== create environment + basic packages
conda create -n torch python=3.9 numpy pyyaml setuptools cmake pandas pillow scikit-image scikit-learn tqdm jupyter notebook matplotlib seaborn

=== GTX 1080
conda create -n torch1080 python=3.10 numpy pyyaml setuptools cmake pandas pillow scikit-image sciki
t-learn tqdm jupyter notebook matplotlib seaborn
pip install torch==1.13 numpy==1.24

pip install pytorch torchvision opencv
